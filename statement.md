# Library Management System

## Problem Statement

Managing books, students, and book transactions manually can be time-consuming and may lead to errors in maintaining records. A library needs a simple system to store book information, student information, issue and return records, and fine details in an organized manner.

The Library Management System is a Python-based application developed to automate these basic library operations. It provides a structured way to manage books and students, issue and return books, maintain transaction history, and generate library reports.

## Scope

The system is designed for small libraries or academic library environments where basic book and student management is required.

The project covers:

- Book registration and management
- Student registration and management
- Book searching and updating
- Book issuing and returning
- Due-date management
- Fine calculation
- Transaction history
- Library reports
- Persistent storage using JSON files
- Input validation and error handling

The system is currently designed as a terminal-based application and can be extended to a graphical or web-based application in the future.

## Target Users

- Librarians
- Library administrators
- Educational institutions
- Students for basic library record operations

## High-Level Features

### 1. Book Management
- Add new books
- Display available books
- Search books
- Update book details
- Remove books

### 2. Student Management
- Register students
- Display student records
- Search students

### 3. Issue and Return Management
- Issue books to registered students
- Return issued books
- Track issue and due dates
- Calculate fines for overdue books

### 4. Transaction Management
- Generate unique transaction IDs
- Maintain transaction history
- Track issued and returned status

### 5. Library Reports
- Total book copies
- Available book copies
- Issued book copies
- Total registered students
- Active borrowings
- Overdue books
- Total recorded fines

## Technology Used

- Programming Language: Python
- Data Storage: JSON
- Application Type: Terminal-based application
- Version Control: Git and GitHub

The main objective of this project is to develop a modular and reliable Library Management System that demonstrates programming concepts such as:

- Object-Oriented Programming
- Functions and modular programming
- File handling
- JSON data storage
- Input validation
- Exception handling
- Date and time operations
- Data processing and reporting
